# Android から Codex セッションを制御する

- 案1: 公式 Codex Remote を使う
    - Windows の ChatGPT デスクトップアプリで `Settings > Connections > Control this PC > Set up` を開く
    - 表示された QR コードを Android の ChatGPT アプリで読み取る
    - 同じ ChatGPT アカウントとワークスペースで接続する
    - Android からタスクの開始、追加指示、承認、差分・テスト結果の確認を行う
    - PC は起動・オンライン状態を維持する
    - 利用可否は段階的ロールアウトとワークスペース設定に依存する
    - LAN 内限定の接続ではない点に注意する
    - 公式ガイド: https://learn.chatgpt.com/docs/remote

- 案2: LAN 内限定で SSH + tmux を使う
    - 実装と詳細手順: `../../codex/README.ja.md`
    - [自動] WSL2側の `codex`、`tmux`、SSH、Windows OpenSSHを診断する
    - [手動] AndroidにTermuxとOpenSSHをインストールする
    - [自動] Android内に専用SSH鍵と接続コマンドを作る
    - [手動] Androidの公開鍵だけをWindowsへ渡す
    - [手動] 管理者PowerShellを開き、UACを承認する
    - [自動] Windows OpenSSH Server、Private LAN用ファイアウォール、公開鍵を設定する
    - [手動] 初回接続時にWindowsホスト鍵のフィンガープリントを確認する
    - [自動] Windows経由でWSL2へ入り、Codexのtmuxセッションを作成または再接続する
    - [手動] モバイル回線から接続できないことを確認し、ルーターでTCP 22を公開しない

- 案3: Windows OpenSSHを介さず、AndroidからWSL2へ直接SSH接続する
    - 実装と詳細手順: `../../codex/README.direct-wsl.ja.md`
    - [自動] WSLのOpenSSH ServerをTCP 2222、公開鍵認証限定で構成する
    - [自動] Android公開鍵をWSLユーザーの `authorized_keys` へ登録する
    - [手動] 管理者PowerShellを開き、UACを承認する
    - [自動] WSLをmirrored networkingへ設定し、Hyper-V firewallでTCP 2222だけを許可する
    - [手動] 作業を保存し、`wsl --shutdown` でWSL2を再起動する
    - [自動] AndroidにWSL直接接続用の `ghost_codex_direct` を作る
    - [手動] WSLのSSHホスト鍵指紋を照合して初回接続する
    - [確認] Windowsの `sshd` と `wsl.exe` が通信経路に含まれないことを確認する
    - [保留] 案3の動作確認後、案2で導入したWindows OpenSSHを削除するか判断する
